zephrctl

A tiny CLI over a Unix socket. Nothing requires it — hotkeys and the palette cover everything — but it makes scripting and bar integrations one-liners.

Install

just cli
# or by hand:
cp tools/zephrctl /usr/local/bin/ && chmod +x /usr/local/bin/zephrctl

The socket lives at ~/Library/Application Support/Zephr/zephr.sock while Zephr runs. Protocol: one command per line in, one JSON reply per line out — trivially scriptable without the wrapper too.

The event stream

zephrctl subscribe keeps the connection open and emits one JSON object per line:

{"event":"workspace_changed","workspace":"3"}
{"event":"focus_changed","app":"com.googlecode.iterm2","title":"zsh","window":"12885"}
{"event":"window_managed","app":"com.apple.Safari","title":"…","window":"30065"}
{"event":"window_unmanaged","app":"com.apple.Safari","window":"30065"}
{"event":"display_changed","displays":"2"}

SketchyBar in two lines

# sketchybarrc — a workspace indicator driven by the stream
zephrctl subscribe | while read -r line; do
  ws=$(echo "$line" | jq -r 'select(.event=="workspace_changed").workspace')
  [ -n "$ws" ] && sketchybar --set zephr label="$ws"
done &

Or skip the stream entirely and use the config callback:

[callbacks]
on-workspace-changed = ["sketchybar --trigger ws_change WS=$ZEPHR_WORKSPACE"]

Recipes

# Jump straight to whatever Safari window is anywhere
zephrctl list-windows | jq -r '.[] | select(.app=="Safari") | .id' \
  | head -1 | xargs zephrctl focus-window

# Pause tiling while a screen-share app runs
zephrctl pause; open -W /Applications/zoom.us.app; zephrctl resume

# Health check in scripts
zephrctl doctor | jq -e 'all(.status=="pass")' >/dev/null || echo "zephr unhappy"
