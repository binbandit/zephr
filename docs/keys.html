The complete keymap

Two ways to do everything: the leader layer (discoverable) and direct chords (fast). Both always work.

Leader

Default ⌥ Space — toggles the command layer. Change it with leader = "ctrl-alt-space" (any of ctrl/alt/cmd/shift plus a key, at least one of ctrl/alt/cmd). While the layer is open, all keys are consumed by Zephr; esc or the leader closes it.

Resize mode

Leader r, then:

KeyAction
l or → · j or ↓Bigger — wider, taller. 5% steps
h or ← · k or ↑Smaller — narrower, shorter
⇧ + any of thoseFine steps (1%)
esc or rBack to the layer

The direction is where the window's far edge goes: right and down grow it, left and up shrink it. That holds wherever the window sits — a tile at the end of a row grows by taking from the neighbour behind it rather than reversing on you.

Chord presets

The chord modifier is a preset — set preset under [keys] or pick it in Settings. The leader layer is identical in all of them.

PresetChords useWho it's for
default⌃⌥ / ⌃⌥⇧Everyone. No collisions with ⌥-typing, Emacs, or IDEs.
i3⌘⌥ / ⌘⌥⇧$mod-style muscle memory on the Command cluster.
aerospace⌥ / ⌥⇧AeroSpace migrators who want their exact chords. Warning: bare ⌥ breaks ⌥-character typing (é, ˙, …) by design of the preset.
vimnoneLeader-only purists — chords disabled entirely.

Layer behavior options

ConfigEffect
[keys] one-shot = trueThe layer closes after a single command (default: sticky)
[keys] layer-timeout = 5Close a forgotten layer after N seconds (default 0 = never)
Secure Input: when a password field or security tool holds the keyboard, macOS mutes event taps. Zephr shows a menu-bar warning and automatically falls back to system hotkeys for the ⌃⌥ chords; the leader layer resumes when Secure Input ends.
Key positions, not letters: bindings are by physical key position (ANSI). On Dvorak/Colemak the direction keys sit where QWERTY's h j k l are. Full rebinding arrives with the settings engine.
