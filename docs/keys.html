The complete keymap

Two ways to do everything: the leader layer (discoverable) and direct chords (fast). Both always work.

Leader

Default ⌥ Space — toggles the command layer. Change it with leader = "ctrl-alt-space" (any of ctrl/alt/cmd/shift plus a key, at least one of ctrl/alt/cmd). While the layer is open, all keys are consumed by Zephr; esc or the leader closes it.

Resize mode

Leader r, then:

KeyAction
l or → · j or ↓Bigger — wider, taller. 5% steps
h or ← · k or ↑Smaller — narrower, shorter
⇧ + any of thoseFine steps (1%)
esc or rBack to the layer

The direction is where the window's far edge goes: right and down grow it, left and up shrink it. That holds wherever the window sits - a tile at the end of a row grows by taking from the neighbour behind it rather than reversing on you. If neither neighbour has room left, the key does nothing rather than doing the opposite.

The ⌃⌥- / ⌃⌥= chords are a slightly different tool: they shrink or grow the focused window's share of its own container and spread the difference across all its siblings, so they work without picking an axis.

Chord presets

The chord modifier is a preset — set preset under [keys] or pick it in Settings. The leader layer is identical in all of them.

Binding your own keys

A [[bind]] block binds any key to any command. The command names are the same vocabulary zephrctl speaks, so anything you can run from the shell you can put on a key.

[[bind]]
key = "ctrl-alt-b"      # a chord
command = "balance"

[[bind]]
key = "leader z"        # a bare key, only while the layer is open
command = "summon 2"    # bring workspace 2 to this display

[[bind]]
key = "leader shift-o"
command = "layout column"

Trigger syntax: a chord is ctrl/alt/cmd/shift joined with dashes and ending in a key (a–z, 0–9, space, tab, grave), and needs at least one of ctrl/alt/cmd - a bare letter bound globally would swallow that key in every app. A layer binding is leader <key> or leader shift-<key>.

Your bindings are checked before the built-in tables, so binding ctrl-alt-h replaces focus-left. There is no way to unbind a built-in key and have it pass through to the app underneath; you can only point it somewhere else. A binding Zephr can't understand is reported in the menu bar and skipped, and the rest of the file still loads.

Secure Input: when a password field or security tool holds the keyboard, macOS mutes event taps. Zephr shows a menu-bar warning and falls back to system hotkeys for the built-in chords - focus, move, workspaces, float, monocle, close, palette, shrink/grow and next-display. Two things do not survive the fallback: ⌃⌥⇧` (send window to display) and your own [[bind]] chords. The leader layer resumes when Secure Input ends.
Key positions, not letters: bindings are by physical key position (ANSI). On Dvorak/Colemak the direction keys sit where QWERTY's h j k l are, and a [[bind]] key name means that same position.
